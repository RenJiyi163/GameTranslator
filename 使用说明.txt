游戏翻译器 使用说明

一、添加游戏

1. 双击 GameTranslator.exe，开一个窗口，中间是游戏列表。
2. 点「添加游戏…」，选中游戏的 exe（一般叫 Game.exe，和游戏数据在同一个文件夹里）。
3. 程序会自己认引擎。现在能翻译的是 RPG Maker MV / MZ 和 Ren'Py 做的游戏。认出 Unity、Unreal、Electron、RPG Maker VX Ace 这类时，会说明为什么还不能加，不会装着能跑。
4. 给游戏起个名字，确定。列表里就多一行，配置存在 profiles 文件夹下面。

二、开始翻译

1. 在列表里选中游戏，双击这一行也可以。
2. 下面两个勾：
   - 游戏已经开着：游戏已经启动的时候保持勾选，程序只接上去，不会把游戏重启一遍。游戏还没开就先取消勾选，程序会自己把游戏拉起来。
   - 只查词库，不调用模型：平时保持勾选。本机模型没开的时候必须勾着，否则没命中的句子会排队等一个不会来的模型。
3. 按「开始翻译」。等一两秒，窗口下方会出现「已连接」，游戏里的菜单、对话、状态页就逐步变成中文。
4. 按 Ctrl+Shift+T 可以在中文和原文之间来回切。开始翻译时这个键会注册成全局热键，所以游戏窗口在前台也能用；如果这个键被别的软件占着，就退回成游戏窗口内的切换。
5. 按「停止」，游戏立刻还原成日文。直接关窗口不会停，程序会缩到托盘继续翻译，见第三节。游戏文件自始至终没有被改过，所有替换都只在内存里。

三、托盘、悬浮窗与运行记录

1. 关掉主窗口，程序缩到屏幕右下角的托盘，图标是蓝底白字的「译」。右键图标有：显示主窗口、开始翻译、停止翻译、显示或隐藏悬浮窗、运行记录、退出。要彻底关掉就点「退出」。
2. 开始翻译时会自动弹出悬浮窗，显示命中率（词库命中加缓存命中，除以已看条数）、已看条数和已替换条数。它一直在最上面，可以拖到不挡字的地方，点右上角 × 关掉，位置下次会记住。主窗口和托盘菜单里都能再打开。
3. 主窗口的「运行记录…」有两个分页。「运行日志」是 logs\gt.log 的尾部，可以只看警告和错误；「未命中的句子」是当前游戏这次没翻出来的原文，双击一行会复制，方便拿去搜或问人。

四、游戏列表

- 词库：这台机器上已经给这个游戏攒了多少条译文。0 表示还没建词库，游戏里的字会先照原样显示。
- 上次运行：最近一次按「开始翻译」的时间。
- 状态：游戏 exe 找不到了会显示「路径失效」，这时按「修改…」重新指一下。
- 「修改…」可以改名字、改 exe 路径、改调试端口、改翻译策略和后端。端口是自动挑的空闲端口，一般不用动；两个游戏同时开着的时候各用各的端口。
- 翻译策略三种：只查词库（不调模型）、词库优先后端兜底（默认）、全走后端（跳过词库重翻，翻过的不再花第二次钱）。后端选「跟随默认」就用模型设置里定下的那一个。
- 「删除」会把配置和词库一起删掉，删之前会告诉你要删掉多少 MB。游戏本身不受影响。

五、模型设置

点主界面的「模型设置…」：

- 「模型后端」页是给整台电脑用的。左边挑一个后端，右边填地址、密钥、模型。本地模型（LM Studio）和 DeepSeek 各有一份默认配置，密钥要自己填。
- 「拉取模型」列出这个地址上有哪些模型，选一个填进「模型」。「测试连通」只检查连得上、密钥认不认，不花额度、不发翻译。
- 温度、最大 token、超时按需要改。本地模型一次只答一个请求，并发留 1；DeepSeek 这类可以调到 2 到 4。
- 最下面的「没有单独指定后端的游戏用」决定新游戏默认走哪个后端，选「只查词库」就都不调模型。
- 「术语表」页是当前选中游戏的固定译法，一行一条，左边原文右边译文，「添加 / 更新」和「删除」改完按「保存」。翻译时这一批文字里出现的术语会一起交给模型，让它照着说。
- 保存后要停一下再重新开始翻译，新设置和新术语才生效。

密钥是明文存在 backends.json 里的，这个文件不要发给别人。

六、补译文

1. 跑一段游戏再停下。词库翻不出来的句子，程序会自动记下来。
2. 点「导出未命中…」，会在 profiles\<游戏>\export\ 里生成一个 Word 和一个同名的 .jsonl。Word 是给人翻的，jsonl 是导入时配对用的，别拿去翻。
3. 把 Word 交给文档翻译服务，翻完把回传的 Word 存到同一台电脑上。
4. 点「导入回传译文…」选那个 Word。程序会把译文对回原文，好的进词库，对不上的列进报告，下次开始翻译时生效。

回传的 Word 和导出的那个 jsonl 要配套。如果导入时提示找不到映射，就重新导出一次再走一遍。

七、没反应怎么办

先看主窗口的「运行记录…」，最近一次发生了什么、报错在哪都在里面。日志文件本身是 logs\gt.log。

常见情况：

- 「出错：...」里提到端口，多半是游戏没有带调试端口启动。取消「游戏已经开着」的勾，让程序自己启动游戏。
- 窗口一直停在「正在启动」：游戏第一次启动要几十秒，等它。超过一分钟还没反应就看日志。
- 游戏里还是日文：确认游戏里没有按过 Ctrl+Shift+T 切到原文模式，再看窗口下方「词库命中」的数字有没有涨。

八、换一台电脑

1. 在列表里选中一个游戏，菜单「工具 → 导出游戏包…」，得到一个 .gtpack 文件，里面是这个游戏的配置、术语表与词库。
2. 拷到另一台电脑，菜单「工具 → 导入游戏包…」选它。本地已经有同名游戏时，会问是保留本地配置只并词库，还是连配置一起覆盖。
3. 命令行是同一套：gt pack export --profile <游戏id>、gt pack import <游戏id>.gtpack。
4. 整台电脑搬走也可以直接拷文件夹，GameTranslator.exe 和 profiles 在同一个目录里就行。backends.json 存模型设置、ui.json 存悬浮窗位置，一起带走就不用重配。

九、安装与更新

1. 安装包是 GameTranslator_Setup.exe，装到当前用户目录，不需要管理员权限，桌面和开始菜单会有快捷方式。要卸载就在 Windows 的「已安装的应用」里找「游戏翻译器」，或者点安装目录里的 uninstall.cmd。
2. 有更新地址时，菜单「工具 → 更新设置…」把它填进去。之后每次启动会查一次，有新版本时窗口下方会提示；「工具 → 检查更新…」也能手动查，确认后程序下载、校验、退出、替换、重开，配置和词库都保留。
3. 没有更新地址不影响使用，自动检查可以关掉。

Ren'Py 游戏的额外说明：只翻对话与选项，主菜单和存档界面仍是原文；没命中词库的句子会等模型，最长等 12 秒，等不到就显示原文。程序不会往游戏目录写任何东西。

九、词库

中文是从词库查出来的，词库存在 profiles\<游戏>\tm.sqlite。词库条数在列表里能看到。词库是空的也能用，句子会交给后端翻译，翻过的记进缓存，下次直接取用。

游戏里出现词库里没有的句子，会原样显示日文。要补的话找开发者重新导出、翻译、建库。
